# Contributing

Thanks for considering a contribution to PackLedger.

## Local Setup

```bash
npm install
npm test
npm start
```

## Pull Requests

- Keep changes focused on one bug fix or feature.
- Add or update tests when behavior changes.
- Run `npm run build` before opening a PR.
- Include screenshots for UI changes.

## Issue Triage

Maintainers use these labels:

- `bug`: confirmed defects
- `enhancement`: feature requests
- `good first issue`: small scoped work
- `documentation`: docs-only changes
- `question`: support or clarification
