# PackLedger v0.1.1

Maintenance release focused on a small usability improvement from the v0.2.0 roadmap.

## Highlights

- Add built-in package templates for homework, job application, and event registration submissions.
- Keep template content local and editable before package creation.
- Add test coverage for template lookup behavior.

## Verification

- `npm run build`
- `npm run dist:win`

## Asset

Attach `release/PackLedger 0.1.1.exe` to the GitHub Release.
