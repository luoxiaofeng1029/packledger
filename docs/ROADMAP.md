# Roadmap

This roadmap is intentionally small and maintenance-focused. PackLedger should stay useful for everyday submission packages instead of becoming a general file manager.

## v0.2.0

- Compare two PackLedger manifests and show added, removed, and changed files.
- Add package templates for homework, job applications, and event submissions.
- Improve empty-state and error-state copy in the desktop app.

## v0.3.0

- Add verified macOS and Linux builds.
- Add optional password-protected ZIP export if a maintained dependency can provide it safely.
- Add exportable HTML report.

## Maintenance Priorities

- Keep local-first privacy guarantees.
- Review dependency updates monthly.
- Triage new issues with `bug`, `enhancement`, `documentation`, or `question`.
- Cut patch releases for data-loss, packaging, or checksum bugs.
