# PackLedger v0.1.0

Initial public release.

## Highlights

- Build a ZIP package from selected files and folders.
- Generate `manifest.csv`, `checksums.sha256`, `README.txt`, and `packledger-report.json`.
- Preview file count, total size, paths, and SHA-256 hashes before packaging.
- Keep all file processing local on the user's computer.
- Add CI, tests, issue templates, PR template, security policy, support policy, changelog, and release checklist.

## Verification

- `npm run build`
- `npm run dist:win`
- Electron startup smoke test
